# Системные семейства ruaccent:
# 1) неверная ё-вставка при дизамбигуации омографов (58 шт.): само+ё, н+ёбо-семейство
#    (23/23 контекста — небо, ротового нёба в книге нет), л+ёвой, л+ёт (род.п. от «год»;
#    самол+ёт/пол+ёт/л+ётчик корректны и не тронуты)
# 2) потеря буквы (19 шт.): бльш+… (18, ruaccent роняет «о» из «больш…»), мньшим, временн+я
# 3) сдвиг маркера на частых словах: +именно (131 вхождение в 31 главе!), +импульс (11),
#    мо+ю, темн+о- (8), двойные маркеры (Р+ул+а 36, Х+эдд+он 23, Чж+ан+а 12, Х+а+отик 4)
# 4) точечные сдвиги из агентского аудита (тер+агерц, замерл+а, +опыта, Сюз+и, св+язана,
#    том+ограф, Мог+адишу и др.) — по одному-два на главу
# 5) опечатки перевода/склейки (мыпотеряли, жнаю, Кот-дИвуар, вся связные…)
# Полные списки: scratch/stress-audit-flags.md, scratch/systematic-ruaccent-errors.md
