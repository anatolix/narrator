# Fine Structure — словарь форм (roles_full, 42 главы)

Словоупотреблений: 108241, уникальных форм: 22079, форм с ⚠: 171.

Отброшены формы с одной гласной и меньше, кроме содержащих е/ё.

Колонки: частота · форма (lowercase, без ударений) · ударения в тексте (сколько раз) · ударения pylem · части речи pylem (лемма) — в том же порядке, что ударения, через « ; » · ⚠ = ударение в тексте, которого pylem для этой формы не допускает.
