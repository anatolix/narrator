# stress-audit

Аудит ударений в roles_full для русской аудиокниги: сверка ruaccent-разметки со словарём aot/pylem (патченый pylem с `accent_json`), отчёты форм, LLM-проверка омографов по контексту (8 параллельных прогонов), внесение правок в текст и exceptions.txt.

См. [SKILL.md](SKILL.md). Скрипты — `scripts/`, словарные заметки — `references/`. Живые отчёты и рабочие копии скриптов — `reports/fine-structure-forms/`.

Результат первого применения (26.09.2026, «Тонкая структура», 42 главы): 869 подозрительных форм → ~380 правок, пересинтез 41 главы.
