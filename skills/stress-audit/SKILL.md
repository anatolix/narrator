# Stress Audit — сверка ударений с pylem/aot

Пайплайн проверки ударений (`+` перед ударной гласной) в `books/fine-structure-roles_full/roles_full-ch*.md`. Отработан 26.09.2026: 177+869 форм проверено, ~380 правок внесено. Все отчёты — в `reports/fine-structure-forms/` (там же рабочие копии скриптов).

## Зачем

ruaccent ошибается системно: лишние ударения на частицах (`-нибудь`, `-либо`, `кое-`, `-то`, проклитики `обо`, `из-под`), повелительное наклонение (изуч+ите → изуч+ите), местный падеж и счётная форма ему частично известны, часто неверны. pylem/aot (словарь Зализняка) — второе мнение, но тоже ошибается. Ни один источник сам по себе не истина: финальный вердикт — по контексту и по словарю-норме, спорное решает Анатолий.

## Компоненты

### 1. pylem с патчем accent_json (живой разбор)

Исходники: `/home/vellum/src/pylem` (git), установлен в conda env `main`. Сборка под py3.14: системные cmake+ninja, `pip install --no-build-isolation`, `CXXFLAGS='-include cstdint -include cstdio'`, вложенный pybind11 заменён на v3. Патч `accent_json` в `pylem/binding/main.cpp` + обёртка `MorphanHolder.accent(word, all_forms=False)`: возвращает омонимы с леммой, частью речи, граммемами и ударением. Бэкапы: `main.cpp.bak-20260926`, `__init__.py.bak-20260926`.

Факты о словаре aot (morphs.mrd / morphs.json): 298k лемм, ~104k (35%) с ударениями, 4.2M форм. Ударения по акцентным моделям, хранятся как «гласная от конца». Супплетивные парадигмы (человек/люди) размечены вручную и содержат ошибки (люд+ям вместо л+юдям).

### 2. Таблица форм — `build_form_table.py`

Строит `forms.md`: `частота | форма | ударения в тексте (сколько раз) | ударения pylem | части речи pylem | ⚠`. Фильтр: отбрасываются формы с <2 гласными без е/ё. ⚠ = ударение в тексте, которого pylem не допускает. ~50% ⚠ — ошибки самого pylem, не текст.

### 3. Подозрительные формы — `build_suspected.py`

`suspected_forms.md`: формы, где по тексту и pylem вместе >1 варианта ударения (е/ё не различаются, безударные вхождения не считаются, варианты pylem «ударение не на ё» отброшены). Причины: «в тексте разные» (самое ценное), «pylem: омограф», «текст ≠ pylem».

### 4. LLM-проверка по контексту — `prep.py`, `system.txt`, `merge.py`, `run.sh`-паттерн

`prep.py` раскладывает формы на N пакетов JSON: для каждой — варианты pylem с граммемами + все варианты из текста, до 12 контекстов на вариант (целевое слово в `[[ ]]`, с ударением). Каждый пакет — отдельный вызов `assistant inference send --profile claude-code-opus --timeout-seconds 1500 --max-tokens 32000 --system-prompt "$(cat system.txt)"`, 8 параллельно (background, wait). system.txt — промпт-орфоэпист: вердикты `correct/wrong/mixed/both_ok/unsure`, для mixed — список неверных мест `bad:["chNN:строка"]` и правильный вариант `fix`. Ретрай при битом JSON. `merge.py` собирает `suspected_verdicts.md` сгруппированным по вердиктам, с контекстами ❌/✅.

ВАЖНО: вердикты модели проверять вручную. Пойманные ложные вердикты Opus: «утр+а → +утра» (Анатолий: +утра не говорят никогда), «гран+и» (наоборот, модель была права), обруш+ение, с+отовые.

### 5. Внесение правок — `apply_verdicts.py`, `apply_fix_decisions.py`

Применяют решения ПОСЛЕ одобрения Анатолия: wrong — везде, mixed — только по ссылкам chNN:строка из `bad`. Case-восстановление по оригиналу (заглавная первая буква сохраняется). Промахи = 0 обязательны: скрипт печатает список неприменённых.

### 6. exceptions.txt

`books/fine-structure-roles_full/exceptions.txt` — накопительные правила `было -> стало # комментарий`. Правила:
- Глобальные правила применяются поверх разметки; контекстные — помечаются «ТОЛЬКО по позициям: chNN:строка».
- Отменённые решения Анатолия НЕ удалять, а комментировать: `# ОТМЕНЕНО дата (кто/почему): старое_правило`. Иначе следующий прогон вернёт отменённое.
- При конфликте правил новое решение Анатолия всегда сильнее (имп+ульс → +импульс 26.09).

## Известные системные классы

- **Ё закон**: в слове с ё ударение всегда на ё. Варианты «ударение не на ё» — брак любого источника.
- **Местный падеж/счётная форма**: на ход+у, два час+а, восемь утр+а, в двер+и, в год+у. Ни pylem, ни ruaccent полностью не знают — проверять по контексту. Анатолий: «утра» всегда утр+а.
- **Омографы не снимаются словарём**: замок, мука, стоит, глаза, самого — только контекст/LLM.
- **Числительные после перевода цифр в слова**: ruaccent ошибался (четыр+еста, восемьдес+ят, дес+яти, шестидесят+и, семидесят+и, четырн+адцать, кв+адрат, пят+ью) — всё исправлено, при повторной генерации чисел проверять заново.
- **Имена/топонимы**: норма по носителю, не по словарю (+Адам англ., Ад+ам, Т+омас, +Алекс, Нь+ютон, Л+инкольн, К+енте).
